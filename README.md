# PSUSphere

## Description

PSUSphere is a Django-based web application for managing student organizations, colleges, programs, and memberships.

## Requirements

[Docker Desktop](https://www.docker.com/products/docker-desktop) installed on your machine


## Running the App (For Clients)

1. Create a folder on your machine and place the `for_client/docker-compose.yml` inside it.

2. Open a terminal inside that folder and run:docker-compose up

3. Open your browser and go to: http://localhost:8000


## Running the App (For Developers)

1. Clone the repository: git clone <your-repo-url>

2. Navigate to the project folder: cd Sphere

3. Build and run the container: docker-compose up

4. Open your browser and go to: http://localhost:8000


## Docker Hub
The image is available at: https://hub.docker.com/r/jiyurou/psusphere

## Features

- Manage Colleges

- Manage Programs

- Manage Organizations

- Manage Students

- Manage Organization Memberships

- Django Admin customization

- Fake data generation using Faker
